# 山地救援AI仿真平台 - 运行指南

## 项目结构
```
仿真/
├── backend/              # 后端（Python + Flask + PyTorch）
│   ├── app.py           # Flask API服务
│   ├── environment.py    # 物理仿真环境
│   ├── model.py         # DQN模型与Agent
│   ├── dqn_model.pth     # 预训练模型
│   └── requirements.txt  # Python依赖
└── frontend/             # 前端（Three.js + Vite）
    ├── index.html       # 主页面
    ├── src/
    │   ├── main.js      # 入口文件
    │   ├── scene.js     # Three.js场景管理
    │   ├── terrain.js   # 地形生成
    │   ├── wind.js      # 风力粒子系统
    │   ├── path.js      # 路径可视化
    │   └── api.js       # API调用
    └── package.json
```

## 启动步骤

### 1. 启动后端服务
```bash
cd backend
python app.py
```
后端运行在 `http://localhost:5000`

### 2. 启动前端开发服务器
```bash
cd frontend
npm install   # 首次运行需要安装依赖
npm run dev
```
前端运行在 `http://localhost:3000`

### 3. 打开浏览器
访问 `http://localhost:3000`

## 操作说明

### 控制面板
- **风速滑块**：调节风力大小（0~1），风速越大粒子运动越剧烈，AI会调整路径避开逆风
- **地形起伏滑块**：调节地形陡峭程度（0.5~2.0），值越大山越高，上坡代价越大
- **重新规划按钮**：手动触发AI重新规划路径

### 信息面板
- **路径总代价**：AI选择路径的总消耗（越低越好）
- **路径步数**：从起点到终点的步数
- **AI状态**：显示当前规划状态

### 3D场景操作
- 鼠标左键拖动：旋转视角
- 鼠标滚轮：缩放
- 鼠标右键拖动：平移

## 物理科普知识

### 坡度代价
上坡移动需要消耗更多体力，AI会尽量选择平缓的路线。地形起伏越大，坡度代价越明显。

### 逆风代价
风向从左向右（Y轴正方向），迎风前进会增加阻力。风速越大，AI越倾向于选择顺风或侧风的路径。

### AI决策
DQN强化学习算法通过大量试错学习，综合考虑坡度和风速的影响，找到总代价最小的救援路径。
